Sobre la Materia

Desarrollo Web 1

Introducción a los fundamentos esenciales para la creación de sitios web modernos, accesibles y funcionales. A lo largo del curso, se exploran tecnologías clave como HTML, CSS y JavaScript, así como herramientas y frameworks que permiten construir interfaces responsivas y dinámicas. El enfoque es práctico, orientado al diseño estructurado, la interacción del usuario y el consumo de datos en tiempo real.

Guia 1

  • Usando estilos CSS embebidos en las etiquetas HTML
    Ejercicio práctico que aplica estilos CSS directamente en etiquetas HTML para personalizar diseño sin usar archivos externos o internos.
  • Incluyendo reglas css mediante la etiqueta style
    Ejercicio que aplica estilos CSS internos usando la etiqueta <style> en el documento HTML para controlar diseño y presentación.
  • Usando reglas CSS definidas en archivos externos
    Ejercicio que vincula archivos CSS al HTML para separar estilos del contenido y facilitar mantenimiento y reutilización del diseño.
  • Ejercicio Complementario
    Página desarrollada como ejercicio complementario para presentar la serie Breaking Bad, incluyendo sinopsis, personajes principales, premios, impacto cultural y estilos personalizados con HTML y CSS

Guia 2

  • Usando selectores CSS avanzados
    Ejercicio que emplea selectores complejos como descendientes, hijos directos, pseudoclases y atributos para aplicar estilos precisos y dinámicos.
  • Diseñando un tablero para damas con la pseudo-clase :nth-child()
    Ejercicio que utiliza la pseudo-clase :nth-child() para alternar colores en celdas y construir un tablero de damas con estilo CSS.
  • Biografia
    Autobiografia utilizando etiquetas HTML semánticas, estilos CSS embebidos, internos y externos

Guía 3

  • Usando posicionamiento y visualización
    Ejercicio que aplica propiedades CSS como position, display y overflow para controlar la ubicación y el flujo visual de los elementos en la página.
  • Diseñando un menú horizontal multinivel
    Ejercicio que implementa un menú de navegación horizontal con subniveles desplegables, utilizando listas anidadas y posicionamiento CSS
  • Construyendo un diseño fijo
    Ejercicio que utiliza propiedades CSS como position: fixed para mantener elementos visibles en pantalla, sin importar el desplazamiento del usuario.
  • Ejercicio Complementario Cartas
    Actividad que utiliza la propiedad z-index en CSS para controlar la superposición de cartas, simulando capas visuales en un diseño interactivo.

Guía 4

  • Utilizando los media queries
    Ejercicio que emplea media queries en CSS para adaptar el diseño de la página a distintos tamaños de pantalla y dispositivos, logrando una experiencia responsiva.
  • Construyendo un Layout responsivo
    Actividad que retoma el diseño de una página web sobre viajes y lo adapta a múltiples dispositivos mediante el uso de media queries
  • Ejercicio Complementario
    Mejorar la página de inicio (pagina actual) utilizando flexbox y mediaquerie
